Orb Manager @VERSION@ for Windows
=================================

Double-click orb-manager.exe. It opens its own window; close the window to quit.
You can keep it anywhere: it is the whole program.

Your library (the apps and themes Orb Manager puts on an orb, and anything you
import) lives in %AppData%\orb-manager. The first run fills it with the apps and
the default theme that come with this release. Delete something there and it stays
deleted; a later release only updates files you have not changed. To get the
shipped set back, delete that folder.

Needs: Windows 10 or 11, and Google Chrome or Microsoft Edge (Edge is already on
every Windows 10/11 PC). Orb Manager draws its window with that browser; it does
not install one.

The first time it runs, Windows Firewall may ask whether Orb Manager may use
private networks. Allow it: that is how it finds your orbs on your Wi-Fi.

Plug an orb in with a USB-C data cable to flash or set it up. No driver is
needed.

Using it, step by step: https://github.com/gregtakacs/gorb-os/blob/main/docs/user-guide.md
Problems and ideas: https://github.com/gregtakacs/gorb-os/issues
