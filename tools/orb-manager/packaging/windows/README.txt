Orb Manager @VERSION@ for Windows
=================================

1. Unzip this folder anywhere you like (Documents, for example). Keep the apps
   and themes folders next to orb-manager.exe: they are the library the hub
   installs from, and anything you import is saved there too.
2. Double-click orb-manager.exe. It opens its own window; close the window to quit.

Needs: Windows 10 or 11, and Google Chrome or Microsoft Edge (Edge is already on
every Windows 10/11 PC). Orb Manager draws its window with that browser; it does
not install one.

The first time it runs, Windows Firewall may ask whether Orb Manager may use
private networks. Allow it: that is how it finds your orbs on your Wi-Fi.

Plug an orb in with a USB-C data cable to flash or set it up. No driver is
needed.

orbflash.exe is a command-line flasher for scripting; most people never need it.
